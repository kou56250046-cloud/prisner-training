# スプレッドシート連携の置き方

記録は端末の IndexedDB にしかない。壊れれば全部消えるので、
Google スプレッドシートに写しを取る。記録するたびに全件を送り直すので、
あとから直した記録・消した記録もそのまま揃う。

## 1. スクリプトを貼る

1. 記録先のスプレッドシートを開く
2. 拡張機能 → Apps Script
3. `コード.gs` の中身を全部消して、[`Code.gs`](./Code.gs) を貼って保存
4. 左の歯車「プロジェクトの設定」→ スクリプト プロパティ → プロパティを追加
   - プロパティ: `TOKEN`
   - 値: 自分だけが知っている文字列（例: `pt-8f3k29`）
5. 保存

合い言葉をスクリプトのソースに書かないのは、このリポジトリが公開だから。
スクリプト プロパティなら自分のアカウントの中にしか残らない。
アプリの解錠に使っている合い言葉の使い回しも避けること。

`SPREADSHEET_ID` は記録先のシートの ID が入っている。別のシートに変えるなら
URL の `/d/` と `/edit` の間を貼り替える。スプレッドシートに紐づけたスクリプトなら
空文字 `''` にしてもよい。

## 2. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 種類を選択（歯車）→ **ウェブアプリ**
3. 次のとおり設定する
   - 説明: 何でもよい
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. デプロイ → 権限を承認（「安全ではないページ」の警告は自分のスクリプトなので進んでよい）
5. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピー

「アクセスできるユーザー: 全員」は、URL を知っている人なら誰でも叩けるという意味。
書き込みは `TOKEN` で止めているので、合い言葉は推測しにくいものにして人に見せないこと。

## 3. アプリ側に登録する

アプリの 設定 → スプレッドシート連携 に、URL と合い言葉を入れて「今すぐ同期」を押す。
成功すると次のシートが作られる（既にあれば中身が置き換わる）。

| シート | 内容 |
|---|---|
| 記録 | 1セット1行。日付・種目・STEP・目標・実績 |
| 日別 | 1日1行。セット数・総レップス・きつさ・種目 |
| ステップ別 | ステップごとの累計・自己ベスト・最終実施 |
| 進捗 | ビッグ6それぞれの現在STEPと解禁STEP |
| バックアップ | 復元用の生データ（非表示シート。触らなくてよい） |

以降は記録・修正するたびに自動で送られる。オフラインだったときは、
次に記録したときか「今すぐ同期」でまとめて送り直される。

## 4. 端末を変えたとき

新しい端末で 設定 → スプレッドシート連携 に同じ URL と合い言葉を入れ、
「スプレッドシートから復元」を押す。バックアップシートの生データで端末の記録を置き換える。

## スクリプトを直したら

Apps Script で編集しただけでは公開中のものは変わらない。
「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→ デプロイ、で反映する。
URL は変わらない。

## うまくいかないとき

| 症状 | 原因 |
|---|---|
| 「応答が読めません」 | アクセスできるユーザーが「全員」になっていない |
| 「合い言葉が違います」 | スクリプト プロパティの `TOKEN` とアプリに入れた文字列が違う |
| 「TOKEN が登録されていません」 | プロジェクトの設定 → スクリプト プロパティ に `TOKEN` がない |
| 「接続できませんでした」 | オフライン、または URL が `/exec` で終わっていない |
| 「送られてきた記録が0件です」 | 記録が入っていない端末から同期した。シートは消さずに中止している |

記録が1件もない状態からの同期は、シートを全消しにしてしまうので拒否する。
端末を替えたときは、先に「シートから復元」で記録を戻してから同期すること。
