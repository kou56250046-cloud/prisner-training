# プリズナートレーニング管理アプリ

書籍『プリズナートレーニング』を、進捗管理とフォーム解説を兼ねた個人用アプリにしたもの。
完全ローカル動作・ログイン不要・無料運用。

## 起動

```bash
npm install
npm run dev        # http://localhost:5173
```

## コマンド

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバー |
| `npm run typecheck` | 型チェック |
| `npx tsx scripts/verify-anim.ts` | 棒人間アニメの幾何を検証（床の突き抜け・接地点のズレ・関節角の異常を検出） |
| `npm run build` | 本番ビルド |

Phase 1（アニメーションエンジン + プッシュアップ STEP1〜3）まで完成。
`/` を開くとプッシュアップの STEP1〜3 を切り替えて確認できる。

## 棒人間アニメーションの仕組み

`src/anim/` に、全60種目で共通のスケルトンリグと再生エンジンがある。

- **絶対角で姿勢を持つ** — 関節角を親からの相対角ではなく「水平から何度」で持つ。
  書籍の写真を見て「体幹は水平から62度」とそのまま書き写せる。
- **接地点は IK でピン留めする** — 壁や床に触れている手足は、関節角ではなく
  「手首のワールド座標」で指定し、逆運動学で関節角を解く。キーフレーム間を
  IK 同士でつなぐと、動作中ずっと接地点がずれない。
- 角度データは `src/content/animations/*.ts`。1種目あたり通常3キーフレーム。

新しい種目を追加する手順:

1. スキャンの写真ページ（解説ページ + 1）を開く
2. スタート/フィニッシュの関節角度を読み取る（本文中の「45度」などの記述で裏取り）
3. `src/content/animations/` にキーフレームを書く
4. `npx tsx scripts/verify-anim.ts` で破綻がないか確認
5. ブラウザで再生して微調整

## ディレクトリ

```
src/
  anim/           棒人間エンジン（リグ・IK・補間・SVG描画・再生UI）
  content/
    types.ts      種目とステップのデータ型
    steps/        書籍から起こしたステップ解説
    animations/   関節角度のキーフレーム
  screens/        画面
scripts/
  verify-anim.ts  アニメの幾何検証
```

## 原本の参照方法

スキャン画像はリポジトリに含めない。ページ番号 = スキャンのファイル番号（オフセット0）。

- 偶数ページ = 解説（やり方 / 説明 / トレーニング・ゴール / 技術を完璧にするために）
- 奇数ページ = スタートとフィニッシュの写真2枚
